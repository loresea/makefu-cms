## 9. 发布标准

只有以下全部完成才标记 `1.0.0 Stable`：

1. 真实 PHP 环境首次安装成功；
2. SQLite CRUD、媒体上传、表单提交正常；
3. SQLite → MySQL 实际迁移成功；
4. 4 套模板至少真实运行 1 套，其他模板不破坏核心；
5. 插件安装 / 升级 / 卸载通过；
6. Core 在线升级和失败回滚通过；
7. 备份恢复通过；
8. PHPUnit / 静态检查 / Browser Smoke Test 通过；
9. 生产环境 `APP_DEBUG=false`；
10. 无 P0 / P1 阻断问题。
