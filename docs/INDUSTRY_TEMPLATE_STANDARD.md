# 行业模板产品标准

从装修行业开始，码科服 CMS 的行业模板统一按以下规则建设。

## 数量
- 每个行业目标：6 套可独立安装的成品模板。
- 200 个行业长期目标：1200 套行业模板。
- 模板不是换色皮肤；每套需有独立品牌、视觉方向、首页结构、导航结构、图片调性和内容节奏。

## 行业模块
模板必须先定义行业信息架构，再做视觉设计。不同业务不能强行套统一“产品”结构。

示例：
- 装修：装修案例 / 效果图 / 装修服务 / 设计风格 / 材料工艺 / 设计团队 / 装修知识 / 预约量房。
- 旅游：目的地 / 旅游线路 / 私人定制 / 顾问 / 游记 / 预约咨询。
- 手机零售：手机产品 / 型号详情 / 参数 / 配件 / 对比 / 门店 / 售后 / 新闻。

## 页面完整性
可安装模板必须有完整页面闭环，不能只做首页：
- 首页
- 栏目列表页
- 业务详情页
- 案例/项目列表页
- 案例/项目详情页
- 内容列表页
- 内容详情页
- 团队及成员详情（适用行业）
- 关于
- 联系/预约
- 404

任何“查看详情”“了解服务”“阅读全文”“查看设计师”等操作必须进入实际详情页。

## 排版规则
- 桌面列表不得出现只有 1 个卡片单独占最后一行的孤项。
- 4 列布局优先 4 / 8 / 12 条；3 列布局优先 3 / 6 / 9 条；2 列布局优先 2 / 4 / 6 条。
- 允许有设计性的跨列卡片，但最终栅格必须闭合，不得制造明显空白区。
- 手机端一列属于正常响应式行为，不受该规则限制。

## 质量底线
- 文本与背景必须保持明确对比。
- 页面不得出现破图、黑块、空模块或动效导致的隐藏内容。
- 同一列表页避免重复图片。
- 导航必须覆盖该行业核心信息，不得为视觉差异删掉真实业务功能。
- 每套模板必须同时完成桌面、平板与手机布局。
