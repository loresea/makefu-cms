# 行业模板切换与内容包策略

这是码科服 CMS 的重要规则：**模板（Theme）和内容（Content）必须分开管理。**

## 为什么不能“切模板就自动覆盖所有内容”

一个正在运营的网站可能已经有真实文章、产品、案例和 SEO 数据。

如果从旅游模板切到装修模板时直接覆盖数据库：

- 真实内容可能丢失；
- URL 和 SEO 会变化；
- 用户无法安全试用模板；
- 切回旧模板也难以恢复。

因此 **切换模板默认只切换展示层，不覆盖真实内容**。

## 模板安装包包含什么

模板可以包含：

1. 页面布局 / Blade Views
2. CSS / JS / 图片资源
3. 模板配置 Schema
4. 推荐菜单结构
5. 推荐内容模型 / 自定义字段
6. 所需插件依赖
7. 一个可选的“行业起步内容包”

行业起步内容包不等于模板核心文件。

## 启用模板时提供三种模式

### A. 仅切换外观与结构（默认，最安全）

适用于已经上线的网站。

- 保留文章、产品、案例、表单数据；
- 保留原有 URL；
- 加载新模板；
- 新模板需要但现有站没有的数据区块，显示“待配置”状态；
- 不自动写入示例文案。

### B. 导入行业起步内容，只填空白项

适用于刚创建、内容很少的网站。

例如切换到“装修行业”：

- 如果没有主菜单，则创建装修菜单；
- 如果没有首页 Hero，则写入装修行业默认 Hero；
- 如果没有案例分类，则创建“住宅设计 / 旧房改造 / 商业空间”等分类；
- 如果字段已有内容，则绝不覆盖。

所有导入记录写入 `content_pack_imports`，以后可以识别哪些内容是系统导入的。

### C. 完整应用行业演示内容

仅用于新站 / 测试站。

流程必须：

1. 创建数据库备份；
2. 创建当前内容快照；
3. 显示将被替换的数据范围；
4. 用户二次确认；
5. 导入行业完整 Demo；
6. 保留恢复点。

正式运营网站不推荐此模式。

## “模板专属内容”怎么处理

部分行业需要特殊模块，例如：

旅游：
- 目的地
- 旅行路线
- 旅行顾问

装修：
- 装修案例
- 设计师
- 装修风格
- 工艺节点

代理记账：
- 服务套餐
- 财税流程
- 风险提示

律师：
- 专业领域
- 律师团队
- 典型案例
- 法律观点

这些能力优先使用：

1. 通用 CMS 模型 + 自定义字段；
2. 内容区块；
3. 必要时使用独立插件。

不要把行业业务逻辑硬编码到 Theme 里。

## 数据绑定

模板声明自己需要的 Slot：

```json
{
  "slots": {
    "hero": "block:home-hero",
    "featured_products": "products:featured",
    "latest_articles": "articles:latest",
    "global_cta": "block:global-cta"
  }
}
```

CMS 在启用模板时检查：

- Slot 是否有数据；
- 没有则显示配置向导；
- 起步内容包可以只填补缺失 Slot。

## 切回旧模板

因为模板和数据分离：

- 切回旧模板时真实数据仍然存在；
- 模板自己的 Settings 独立保存；
- 每个模板保留自己的配置；
- 内容包导入记录可追踪；
- 如果执行过“完整演示数据覆盖”，可从备份恢复。

这也是码科服 CMS 后续能够安全维护大量客户网站的基础。
