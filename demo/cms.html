API / 开发者

前台 Blade、独立前端、小程序统一使用同一套内容服务，不允许模板直接查数据库。

只读 API 已启用

PHP / Blade Helper

cms_site('site_name'); cms_menu('main'); cms_banners('home_hero'); cms_articles(['limit' => 6, 'recommended' => true]); cms_products(['limit' => 8, 'category' => 'laser']); cms_cases(['limit' => 6]); cms_block('global-cta'); cms_form('contact');

所有 Helper 底层统一走 FrontendContentService。

REST API

GET /api/v1/site GET /api/v1/menus/main GET /api/v1/banners/home_hero GET /api/v1/pages/{slug} GET /api/v1/articles GET /api/v1/products GET /api/v1/cases GET /api/v1/blocks/{slug} GET /api/v1/forms/{slug} GET /api/v1/search?q=keyword

列表支持分页、分类、搜索、推荐筛选；API 与 Blade 共用同一查询逻辑。

统一数据契约

后台字段、Blade Helper、REST API 使用同一服务层，减少前后台数据不一致。

草稿预览

后台预览生成 30 分钟临时签名链接，新窗口打开；草稿不需要先发布。

全站搜索

页面、文章、产品、案例统一搜索接口，为站内搜索和小程序提供数据。
